# 离线单页待办管理工具 · 设计文档

日期：2026-08-26
状态：已与用户逐段确认

## 1. 概述

一个**单文件、零依赖、离线可用**的个人待办事项管理网页（`todo.html`），用于不联网的 Windows 电脑，以 Edge/Chrome 通过 `file://` 协议打开使用。

核心价值：防分心的"今日"工作流（inbox → 正在处理 ≤2 → 完成），配合聚焦计时、休息提醒、每日收尾总结。

### 约束

- 目标电脑离线：不能依赖任何 CDN 字体/图标/库，不能 npm 安装、不能构建
- `file://` 协议下 ES 模块被 Chrome/Edge 阻止（CORS），因此采用单文件内联传统 script
- 数据存 localStorage（刷新不丢），怕浏览器数据被清理 → 附加自动文件备份

### 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 技术形态 | 单文件 `todo.html`，HTML+CSS+JS 全内联，零依赖 |
| 存储 | localStorage + File System Access API 自动备份到本地 JSON（不支持时回退手动导出） |
| 跨天时未完成事项 | 自动滚入次日 inbox（保留标签/子任务/累计聚焦时长），标记"遗" |
| 最低完成线语义 | 规则只作用于设置当天，次日自动失效（红点随之消失） |
| 默认标签 | AI处理、抛球、脚本、时效、等回复、无脑、深度、沟通（共 8 个，可增删改配色） |
| 增强项 | 快捷键、已完成复活、收尾含子任务；**不做**每日快照回滚 |

## 2. 数据模型

单个 localStorage 键 `todoApp.v1`，值为一份 JSON。每次状态变更即写 localStorage，并 debounce 同步备份文件。

```js
{
  version: 1,
  lastActiveDate: "2026-08-26",        // 上次活跃日期（本地时区 YYYY-MM-DD），跨天检测用
  tasks: [                              // 今日全部事项（inbox/doing/done 三区共用）
    {
      id: "t_1693039200123_x8k",       // Date.now()+随机后缀
      text: "MySQL 压测",
      zone: "inbox" | "doing" | "done",
      labels: ["脚本", "时效"],          // 引用 settings.labels 的名称
      subtasks: [{id, text, done}],
      focusMs: 0,                       // 事项累计聚焦毫秒（跨天保留，展示"已投入"）
      focusMsToday: 0,                  // 当日聚焦毫秒（跨天清零，供最低完成线判断）
      minLine: null,                    // {type:"focus", minutes:30} | {type:"subtask", count:1} | null
      minLineMet: false,                // false=红点，true=绿点
      rolledOver: false,                // 是否遗留滚入（界面显示"遗"角标）
      createdAt: 1693039200123,
      completedAt: null
    }
  ],
  todayFocusMs: 0,                      // 今日总聚焦毫秒（顶栏实时展示）
  focusSession: null,                   // {taskId, startAt} | null —— 聚焦中；持久化，刷新不丢计时
  history: [                            // 历史归档，按天一条，日期倒序
    {
      date: "2026-08-25",
      focusMs: 4380000,                 // 当日总聚焦
      tasks: [/* 已完成事项的完整结构，zone 固定为 "done" */]
    }
  ],
  settings: {
    labels: [
      {name:"AI处理", color:"#7C5CFF"}, {name:"抛球",  color:"#F59E0B"},
      {name:"脚本",   color:"#5B8DEF"}, {name:"时效",  color:"#EF4444"},
      {name:"等回复", color:"#94A3B8"}, {name:"无脑",  color:"#10B981"},
      {name:"深度",   color:"#1E293B"}, {name:"沟通",  color:"#EC4899"}
    ],                                  // 首次启动的默认值，均可在设置中修改
    dailyFixed: [ {text, labels, subtasks} ],   // 每日固定事项模板
    maxDoing: 2,                        // 正在处理上限
    focusRemindMin: 45,                 // 单次聚焦满该分钟数，退出时提醒休息
    restMin: 5,                         // 休息倒计时分钟数
    autoBackup: {enabled:false, lastBackupAt:null}  // 备份文件句柄存 IndexedDB
  }
}
```

## 3. 跨天引擎

触发时机：页面加载时 + `setInterval` 每分钟检查 + `visibilitychange` 时检查（标签页切回）。当 `lastActiveDate ≠ 今天`（本地时区）时执行：

1. **归档**：`todayFocusMs` 与 `tasks` 中 `zone==="done"` 的事项写入 `history`（`lastActiveDate` 那天的条目，已存在则合并）
2. **滚入**：昨日未完成事项（inbox + doing）→ 移入今日 inbox，置 `rolledOver=true`；清空 `focusMsToday`、`minLine`、`minLineMet`、`completedAt`；保留 `focusMs` 与 `labels`/`subtasks`
3. **注入每日固定事项**：`settings.dailyFixed` 逐条加入今日 inbox（与今日已有事项按文本去重，已存在则跳过）
4. **重置**：`todayFocusMs = 0`；`lastActiveDate = 今天`
5. **聚焦会话边界**：若归档时正在聚焦，该会话截至归档时刻的时长计入昨日 `todayFocusMs` 后归档；会话本身保留，继续累计到新的一天
6. **多天空缺**：一次性合并处理（数据直接滚入今天），不生成中间空日期的历史条目

## 4. 界面结构

每次只显示一个子界面（顶部 Tab 切换，避免分心）：

```
┌────────────────────────────────────────────────────┐
│ 8月26日 周三   ⏱ 今日聚焦 1h 23min      [设置][导出] │
│ ▓▓▓▓▓▓▓▓░░░░░░░░  今日进度 5/12                     │
│ [ 今天 ] [ 今日已完成 ] [ 历史归档 ]    🔍搜索 #标签  │
├────────────────────────────────────────────────────┤
│              （当前子界面内容区）                     │
└────────────────────────────────────────────────────┘
```

- **顶栏**：日期与星期；今日总聚焦时长（聚焦中实时跳动）；进度条（口径：今日已完成数 ÷ 今日总数，总数 = inbox + doing + done）；三个 Tab；搜索框；标签过滤 chips；设置、导出/导入、今日收尾按钮
- **「今天」页**：正在处理区（上限 `maxDoing`）+ inbox 区（单条添加框 + 批量添加按钮）
- **「今日已完成」页**：当日已完成列表，可拖回/按钮退回 inbox（复活）
- **「历史归档」页**：按日期分组倒序；每组头部显示当日总聚焦时长；支持展开事项查看子任务；单事项可复制、可恢复到今日 inbox

### 事项卡片（三区统一）

- 勾选框：inbox/doing 勾选即完成（记录 `completedAt`，移入 done）
- 文本、标签徽章（带颜色）、子任务进度徽标 `2/5`（有子任务时显示）
- 右上角状态点：红（有 minLine 且未达成）→ 绿（达成）
- "遗"角标：`rolledOver=true` 时显示
- 展开箭头：展开显示子任务列表（默认收起）；展开态可增删改勾选子任务
- 菜单：聚焦 / 设置最低完成线 / 复制 / 恢复到今日（仅历史页）/ 删除（直接删 + toast，不做撤销）

## 5. 功能规格

### 5.1 聚焦模式与计时

- 点事项菜单「聚焦」→ `focusSession = {taskId, startAt}`；该卡片高亮放大 + 大号计时器；**页面其余一切毛玻璃**（`backdrop-filter: blur()`）
- 计时基于时间戳差值，刷新/重开页面不中断
- 同一时间只有一个聚焦事项；聚焦其他事项需先退出当前聚焦
- **退出聚焦**（点取消聚焦，或完成该事项）：结算 `now - startAt`，累计到该事项 `focusMs`、`focusMsToday` 与 `todayFocusMs`；`focusSession = null`
- 达成检查：结算后若 `minLine.type==="focus"` 且 `focusMsToday ≥ minutes*60000` → `minLineMet=true`

### 5.2 休息提醒

- 触发条件：退出的这次聚焦会话时长 ≥ `focusRemindMin`（默认 45min）
- 触发时机：仅在不聚焦的那一刻（退出聚焦/完成事项）弹出，不打断聚焦
- 弹窗文案：**「站起来动动老胳膊老腿！！！」**，按钮：【休息一下】/【暂时忽略】
- 选休息 → 全屏休息倒计时（默认 5min，大数字 + 毛玻璃背景），有【跳过休息】按钮，结束回到原界面
- 选忽略 → 本会话不再提醒；下次聚焦重新计算

### 5.3 最低完成线（防拖延）

- 每事项可设置（菜单入口）：`最低聚焦 X 分钟` 或 `至少完成 1 个子任务`
- 效果：卡片右上角显示**红点**；达成后自动变**绿点**
- 达成时机：聚焦结算时（focus 型）；勾选子任务时（subtask 型，检查已勾选子任务总数 ≥ count；设置时不区分勾选时间，若设置时已达标立即变绿）
- **次日自动失效**：跨天滚入时清除 `minLine` 与 `minLineMet`（规则只管一天）
- 无子任务的事项设置 subtask 型时给出提示（该型需存在子任务）

### 5.4 拖拽

- HTML5 Drag & Drop；区域内上下拖动排序（拖动时显示插入位置指示）
- inbox ↔ doing 互拖；inbox/doing → 已完成（=完成）；已完成 → inbox/doing（=复活）
- doing 已满 `maxDoing` 再拖入：阻止 + toast「正在处理最多 2 条」

### 5.5 复制与批量添加

**统一复制格式**（区域一键复制与单事项复制相同）：

```
[ ] MySQL 压测  #脚本 #时效
    [ ] 建表造数
    [x] 跑压测
[ ] 回复 XXX  #沟通
```

- 已完成事项行首为 `[x]`，未完成为 `[ ]`；标签以 `#名称` 追加在文本后；子任务为 4 空格缩进行
- 每个区域标题旁有「复制」按钮；事项菜单有「复制」

**批量添加**（inbox 区入口，弹窗粘贴多行）：

- 普通多行：每行一个新事项
- 行首若为 `- [ ] ` / `- [x] ` / `[ ] ` / `[x] `，剥离该前缀；`[x]` 前缀视为直接完成
- 若粘贴内容符合复制格式（含 `#标签`、缩进子任务行），完整恢复标签与子任务 → 实现"复制出去 → 下次粘贴回来即恢复"

### 5.6 导入导出

- **导出今日**：JSON 文件（今日 tasks + 标签定义），文件名 `todo-backup-YYYY-MM-DD.json`
- **导出全部**：完整 localStorage 数据（历史 + 设置）
- **导入**：选择文件后选择模式——**合并进 inbox**（不覆盖现有）或**整体替换**（先确认）；兼容备份文件
- 下载用 `<a download>`，导入用 `<input type=file>`，均离线可用

### 5.7 自动备份（File System Access API）

- 设置页「绑定备份文件」→ `showSaveFilePicker()` 选定本地 JSON 文件，句柄存 IndexedDB（授权一次）
- 数据变更 debounce 2s + 每 5 分钟定时：`createWritable()` 全量写入
- `file://` 下 API 不可用时按钮置灰并提示改用手动导出
- 恢复 = 手动导入该文件（不做自动读回）

### 5.8 搜索与标签过滤

- 搜索框作用于**当前范围**：「今天」+「今日已完成」= 今日范围；「历史归档」= 历史范围（分开搜索）
- 匹配事项文本与子任务文本，不区分大小写，实时过滤
- 标签 chips 点击切换选中态，与搜索叠加过滤（AND）

### 5.9 今日收尾

顶栏「今日收尾」按钮 → 弹窗展示 + 一键复制：

```
2026-08-26
聚焦总时长：1h 23min

完成 8 项
遗留 2 项
正在处理 1 项

今天完成：
✓ MySQL 压测
    ✓ 建表造数
    ✓ 跑压测
✓ 监控脚本
...

遗留：
→ 整理监控结论
→ 回复 XXX

正在处理：
→ Hermes 排查
```

- 完成 = 当日 done；遗留 = inbox 未完成；正在处理 = doing 未完成
- 完成项下缩进 `✓` 列出已勾选子任务（已确认包含）
- 时长格式：`Xh YYmin`（不足 1 小时省略小时段）

### 5.10 快捷键

| 键 | 动作 |
|---|---|
| `N` | 聚焦到添加框 |
| `/` | 聚焦到搜索框 |
| `1` / `2` / `3` | 切换 今天 / 今日已完成 / 历史归档 |
| `F` | 聚焦正在处理的第一条（无则 inbox 第一条；已在聚焦中则无操作） |
| `Esc` | 关闭弹窗 / 退出聚焦 |

输入框内按键不触发全局快捷键。

### 5.11 设置页

弹窗形式，含：标签管理（名称/颜色/增删，颜色用原生 `<input type=color>` + 预设色板）；每日固定事项管理（文本 + 标签 + 子任务模板）；`focusRemindMin`、`restMin`、`maxDoing`；绑定/解绑备份文件。修改即时生效并保存。

## 6. 视觉规格

- **配色**：浅色为主；深色模式跟随系统 + 顶栏手动切换（三态：浅/深/自动）；accent 用现代靛蓝 `#4F6DF5`
- **卡片**：白底、圆角 12px、细边框（`#E5E7EB`）、极轻阴影；hover 微上浮；doing 卡片带 accent 左边条
- **字体**：`"Segoe UI", system-ui, sans-serif`；计时器/时长用 `font-variant-numeric: tabular-nums`
- **毛玻璃**：聚焦遮罩与休息界面 `backdrop-filter: blur(8px)` + 半透明底色
- **状态点**：8px 圆点，红 `#EF4444` / 绿 `#10B981`，卡片右上角
- **动效**：tab 切换、卡片进出场等过渡性微动效（150–250ms）；无装饰性动画

## 7. 技术实现要点

- 单文件结构分区：`<style>`（CSS 变量主题）→ `<body>`（静态骨架 + 模板）→ `<script>`（**纯函数核心** 与 **DOM 渲染/事件** 严格分离）
- 纯函数核心（跨天引擎、复制格式生成/解析、批量添加解析、最低完成线判断、收尾总结生成、进度计算）不接触 DOM
- 渲染：状态变更 → 写 store → 重渲染受影响区域（无虚拟 DOM，列表级重绘）
- localStorage 写入：变更即同步（数据量小，无性能问题）
- 所有日期/时间用本地时区，日期字符串 `YYYY-MM-DD`

## 8. 测试策略

- 纯函数核心用 Node 断言测试：仓库内 `tests/` + 一个提取脚本，从 `todo.html` 抽出纯函数块后运行（开发机执行，交付物不含测试依赖）
- 覆盖：跨天引擎（普通跨天/多天空缺/聚焦中跨天）、复制格式生成与解析互逆、批量添加各前缀、min-line 判定、收尾总结格式、进度口径
- 交互（拖拽、聚焦毛玻璃、备份授权、深色模式）用手工冒烟清单逐项验证

## 10. 非目标（明确不做）

- 多设备同步、账号体系、联网能力
- 每日快照回滚（用户已确认不做，备份文件兜底）
- 删除撤销/回收站
- 事项截止时间/日历视图
- 提醒通知（Notification API 在 `file://` 受限，聚焦+休息提醒已覆盖核心诉求）
